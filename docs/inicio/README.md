# Inicio de la web

`abrir-web.bat` abre `frontend/home/index.html` en el navegador predeterminado de Windows. Resuelve la ruta desde la ubicación del propio archivo, por lo que puede ejecutarse desde cualquier carpeta. La web es estática y no requiere iniciar un servidor.

Región: `Inicio web: abrir la pagina principal` en `abrir-web.bat`.
