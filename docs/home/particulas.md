# Fondo de Home

La página contiene 7 símbolos decorativos ocultos a los lectores de pantalla. `scripts/fondo.js` distribuye sus posiciones y contenido aleatoriamente, asigna tamaños de 9 a 22 píxeles y vuelve a aleatorizarlos al repetirse su animación.

La capa de código contiene fragmentos multilínea de JavaScript, Python y SQL. `scripts/codigo-fondo.js` escribe cada carácter cada 75 ms, mantiene el fragmento 2,5 segundos y lo desvanece durante 3 segundos antes de repetir el ciclo. `styles/fondo.css` desplaza los bloques suavemente y mantiene su opacidad baja, detrás del contenido y sin recibir clics. Con movimiento reducido, el código se muestra completo y estático; la preferencia también se aplica si cambia durante la visita.

El HTML contiene el texto de los fragmentos, por lo que queda disponible como decoración incluso sin JavaScript. Las regiones correspondientes delimitan las responsabilidades de cada archivo.

Las estelas eligen entre combinaciones azules, verdes, cálidas y violetas con la misma probabilidad, evitando repetir la anterior. La luz principal también puede adoptar tonos cálidos, verdes, azules o violetas; las partículas combinan cian, ámbar y verde.
